egodiversity — measuring dataset diversity without LLM judges

EgoVerse Data Optimization & Evaluation Suite · Track 2: Quantitative Diversity Measurement

Method

Each episode → one vector from kinematics only: bimanual end-effector paths, wrist orientation, head motion (resampled, shape-normalized) + speed/smoothness stats. No text, no labels, no video decoding.

Similarity = RBF kernel (median heuristic) → Vendi score: effective number of distinct behaviors in any subset.

Validation (it behaves as a diversity score should)

  • Near-duplicates score lower: 3.25 vs 4.67
  • Orders subsets correctly: min < random < max → 1.64 < 5.11 < 5.19
  • Ranking stable across 16× kernel bandwidth range
  • Saturates as redundant episodes are added

Built on Modal

12,542 episodes scored in 3.7 min: one .map() over serverless workers reading zarrs straight from R2 (bit-identical to local), results on a Modal Volume, dashboard deployed as a Modal web endpoint. The entire infrastructure is one Python file — no Docker, no YAML, no IAM.

Finding

≈14 effective distinct behaviors

in 12,212 fold_clothes episodes across 6 labs — heavy redundancy.

Per-episode diversity is nearly identical across labs (Vendi 5.3–5.9 at n=21): scale buys coverage, not variety. The score doubles as a curation signal — keep the k episodes that maximize Vendi.

Deliverables

  • Scalar score that ranks any two subsets + validation report (4 experiments)
  • Interactive dashboard: per-lab pools, greedy max/min-diversity selection, PCA scatter, live comparison
  • Reusable scoring service: SQL manifest → Modal fan-out → feature cache

Honest limits

Kinematics capture motion shape, not scene content; identical motions over different objects score as similar. Visual embeddings on Modal GPUs are the designed extension (same pipeline, one more feature block).
