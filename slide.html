Ego Trip — a diversity audit of EgoVerse, without LLM judges

EgoVerse Data Optimization & Evaluation Suite · Track 2: Quantitative Diversity Measurement

Method

Each episode → one vector from kinematics only: bimanual end-effector paths, wrist orientation, head motion (resampled, shape-normalized) + speed/smoothness stats. No text, no labels, no video decoding. RBF kernel → Vendi score: the effective number of distinct behaviors in any subset.

Validated instrument, not just a number

  • Near-duplicates score lower: 3.25 vs 4.67
  • Orders subsets: min < random < max → 1.64 < 5.11 < 5.19
  • Ranking stable across 16× kernel bandwidth
  • Proof tab: the most-similar / most-distinct episode pairs rendered as real frames — check the score with your own eyes

Built on Modal

12,542 episodes scored in 3.7 min: one .map() over serverless workers reading zarrs straight from R2 (bit-identical to local), results on a Modal Volume, dashboard deployed as a web endpoint. The entire infrastructure is one Python file — no Docker, no YAML, no IAM.

Related work & our delta

Metric: Vendi score (Friedman & Dieng '23); FAKTUAL ('26) applies it to robot datasets via signature kernels. New here: the first audit of EgoVerse, marginal-diversity scoring for collection planning, and a serverless pipeline that makes re-auditing a 4-minute job.

Findings

≈14 effective distinct behaviors

in 12,212 fold_clothes episodes across 6 labs.

Marginal analysis: after any one lab's sample, the other labs add ≈0 new behaviors (ΔVendi −0.3…+0.8) — every source captures the same motions. Adding 600 more episodes to a 200-episode base: +5.4 effective behaviors and flattening. Scale buys coverage, not variety.

Deliverables

  • Score + validation report + marginal-value curve (curation signal: keep the k episodes that maximize Vendi)
  • Live dashboard: compare subsets, spot-check with real video frames, explore episodes, 3D map, comparison history
  • Reusable scoring service: SQL manifest → Modal fan-out → feature cache

Honest limits

Kinematics capture motion shape, not scene content; identical motions over different objects score as similar. Vendi re-standardizes per subset, so marginal deltas can dip slightly negative (read "≈0 new behavior"). Visual embeddings on Modal GPUs are the designed extension.
